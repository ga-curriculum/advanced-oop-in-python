## About
Build reusable data science workflow components for a FreshCart late-delivery prediction scenario. This lesson focuses on core object-oriented programming patterns that data scientists use to make Python code more reusable, testable, and maintainable.


## Learning Objectives

*You will be able to:*

- Implement inheritance, method overriding, and polymorphism.
- Distinguish instance methods, class methods, and static methods.
- Distinguish class attributes from instance attributes.
- Apply Python access conventions and properties.
- Use composition to connect workflow components.
- Use context managers for predictable setup and cleanup.

## Prerequisites
**Before this lesson, you should already be able to:**
- Define and instantiate a Python class.
- Add instance attributes with `__init__()`.
- Write and call instance methods.
- Use functions, loops, conditionals, and exceptions.
- Read basic Python tracebacks.
